# Tarixiy chegaralar (GeoJSON)

Bu papka davrlar bo'yicha tarixiy davlat chegaralarining GeoJSON fayllarini saqlaydi
(2-bosqichda interaktiv xarita uchun, MapLibre GL / Leaflet).

Har bir fayl bitta davlat/davr uchun: `{state-slug}-{yil}.geojson`, masalan
`gokturk-khaganate-600.geojson`.

`properties` da kamida: `name`, `year`, `sourceId` (`src/content/sources/` dagi yozuvga
mos) bo'lishi shart — chegara chizig'i ham fakt hisoblanadi va manbasiz qo'shilmaydi
(CLAUDE.md, ILMIY QOIDALAR).

Hozircha bo'sh — 2-bosqichda to'ldiriladi.
